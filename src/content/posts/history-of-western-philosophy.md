## 各个哲学派别

### 各个哲学学派

主要哲学学派观点与特征总结

以下按传统与时代整理，聚焦最具代表性的学派，用通俗语言说明核心观点和特征。

#### 1. 西方古代哲学（古希腊-罗马）

| 学派 | 核心观点 | 主要特征与代表人物 |
| --- | --- | --- |
| 苏格拉底 |  |  |
| 柏拉图主义 | 在另一个世界（理念世界）。物质世界只是对它的劣质模仿。物质是真理的绊脚石，我们要抛弃感官，回归纯粹灵魂。 |  |
| 亚里士多德主义 | 经验 + 逻辑，追求"中道"与目的论 | 现实主义、分类学、逻辑学之父；亚里士多德 |
| 斯多葛主义 | 接受命运，控制情绪，遵循自然理性 | 坚韧、 cosmopolitan（世界公民）；塞内卡、爱比克泰德 |
| 伊壁鸠鲁主义 | 追求适度快乐，避免痛苦 | 享乐但节制，原子论；伊壁鸠鲁 |
| 怀疑主义 | 一切都不可知，悬置判断 | 反教条，追求内心平静；皮浪 |

#### 2. 西方近代与现代哲学

| 学派 | 核心观点 | 主要特征与代表人物 |
| --- | --- | --- |
| 理性主义 | 理性是知识最可靠来源，天赋观念 | 演绎法、数学化；笛卡尔、斯宾诺莎、莱布尼茨 |
| 经验主义 | 一切知识来自感官经验，"白板说" | 归纳法；洛克、贝克莱、休谟 |
| 德国古典哲学 / 康德主义 | 批判理性，现象与物自体，道德自律 | 调和理性与经验；康德 |
| 黑格尔主义 | 绝对精神辩证发展（正-反-合） | 历史主义、整体论；黑格尔 |
| 存在主义 | 存在先于本质，自由、荒诞、焦虑 | 强调个体选择与真实性；克尔凯郭尔、尼采、萨特、海德格尔 |
| 功利主义 | 最大多数人的最大幸福 | 后果主义、计算快乐；边沁、约翰·穆勒 |
| 马克思主义 | 唯物史观、阶级斗争、剩余价值 | 实践哲学、辩证唯物主义；马克思、恩格斯 |
| 分析哲学 | 语言分析、逻辑澄清、科学方法 | 清晰、实证；维特根斯坦、罗素 |
| 后现代主义 | 反对宏大叙事，解构权力与真理 | 相对主义、碎片化；德里达、福柯、利奥塔 |

#### 3. 中国/东方哲学主要学派

| 学派 | 核心观点 | 主要特征与代表人物 |
| --- | --- | --- |
| 儒家 | 仁、礼、忠恕、中庸，修身齐家治国 | 伦理本位、人文主义；孔子、孟子、朱熹 |
| 道家 | 道法自然、无为而治、顺应变化 | 辩证、隐逸、养生；老子、庄子 |
| 法家 | 法治、术、势，集权管理 | 现实主义、权谋；韩非子 |
| 墨家 | 兼爱、非攻、尚贤、节用 | 功利、科学精神；墨子 |
| 佛教哲学 | 缘起性空、四圣谛、解脱轮回 | 心性论、中观；各种宗派 |

#### 快速记忆口诀（整体特征）

- 柏拉图：看不见的才是真的

- 亚里士多德：看世界本身

- 斯多葛：忍耐与接受

- 伊壁鸠鲁：聪明地享受

- 理性主义：脑子最可靠

- 经验主义：眼睛和感官最可靠

- 存在主义：你必须自己选择并负责

- 儒家：做好人、守规矩

- 道家：别太用力，顺其自然
