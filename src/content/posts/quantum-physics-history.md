## 这本书在讲什么

从 19 世纪末"光的微粒说与波动说"之争写起，一路讲到哥本哈根解释站稳脚跟，横跨约半个世纪。它写的不是公式，而是**一群人怎么把确定性一点点弄丢的**。

## 主线

| 阶段 | 关键节点 |
| :--- | :--- |
| 起疑 | 黑体辐射与"紫外灾难"，普朗克被迫引入能量子 |
| 突破 | 爱因斯坦用光量子解释光电效应；玻尔提出定态跃迁的原子模型 |
| 成形 | 德布罗意物质波；海森堡矩阵力学、不确定性原理；薛定谔波动力学 |
| 解释 | 玻恩的几率诠释——波函数说的不是"粒子在哪"，而是"在哪的概率" |
| 论战 | 索尔维会议上玻尔与爱因斯坦的反复交锋（"上帝不掷骰子"） |
| 余波 | EPR 佯谬、薛定谔的猫，以及后来的多世界解释与退相干 |

## 几个让人印象深的地方

- **每一次"离谱"的假设，都是被实验逼出来的。** 量子化不是天才的灵感，而是经典理论算不下去时的无奈之选。
- **两种数学，一个世界。** 海森堡的矩阵力学和薛定谔的波动力学形式完全不同、结果却等价——这本身就在提示：理论只是描述，不是实在本身。
- **争论的不是对错，是"什么算解释"。** 爱因斯坦不是不信量子力学的计算结果，而是不接受概率成为最终答案。
- **"上帝掷骰子吗"**这句追问，最后成了一场关于科学边界的哲学讨论：物理学说清楚它能说什么，也第一次明确划出了它不再说什么。
